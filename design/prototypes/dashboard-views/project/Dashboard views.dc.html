1Dashboard — Gantt view, new Calendar, one search

Decisions carried in from chat: a project bar runs shoot date → deadline; subtasks move and resize freely, a project bar only drags its deadline edge (shoot date is fixed by the booking); the shell rail holds the only search field and filters whichever view is open; the calendar sidebar toggles are layers + people, with unscheduled tasks below. Built on ReUI gantt-1 and event-calendar-2, re-skinned to the Quincy tokens — square, hairline, monochrome; signal colours only where they carry state. Assumption to confirm: on a non-Dashboard screen, typing in the rail search and pressing Enter returns you to the Dashboard with the query applied.

1aGantt — monochrome (recommended). Full tree columns (Stage · Editor · Deadline). Project = outlined ink bar with a solid shoot diamond (fixed) and a deadline grip (drags). Subtasks = paper bars with progress. Shown mid-drag on “Twilight sky replacement”. View switcher gains Gantt; the toolbar search input is gone.
