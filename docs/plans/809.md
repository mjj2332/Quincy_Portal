# #809 Video notes: resolve/reopen as a green tick toggle

1. Replace the text Resolve/Reopen button in `VideoNoteThread` with an icon toggle (`aria-pressed`) at the bottom-right of the Reply row.
2. Open: outlined muted CircleCheck, name and tooltip "Mark as complete". Resolved: filled `success`-token CircleCheck, name and tooltip "Reopen".
3. Status-only tick (`quincy/ResolvedTick`, sr-only "Resolved") for read-only staff viewers and for the guest page, replacing the guest "Resolved" badge.
4. 44px touch target on coarse pointer / <=721px; global focus ring; disabled while busy; `toggleResolved` unchanged.
5. Tests first: `VideoNoteThread.dom.test.tsx` (toggle, read-only status) and `GuestNotesWrite.dom.test.tsx` (guest tick).

## Reuse ledger

- Resolve/Reopen toggle: `components/reui/button` (`variant="ghost" size="icon"`) wrapped in `IconTip` (`components/quincy/VideoPlayer`), icon `CircleCheck` from lucide-react (already the icon set of this file). Not `quincy/icon-button` (28px base lacks the coarse 44px min-w pairing we need; reui icon + `pointer-coarse:min-*` used as in the anchor button).
- Read-only staff resolved status: `components/quincy/ResolvedTick` (new, shared) = lucide `CircleCheck` + `sr-only` text. Searched through the ReUI MCP (`mcp__ReUI__search` "check icon status", 2026-10-12): the only matches are `@reui/icons` check-circle and siblings (Ultimate-plan Motion Icons, not installed here; this file's icon set is lucide-react, so `CircleCheck` stays) and no component is a bare status glyph; `badge` and `icon-tile` are chips and the owner asked for a bare tick. The tick is a plain 32px `span` (no tab stop, no tooltip): the sr-only "Resolved" carries the meaning, and it sits alone in a right-aligned row under the note body for read-only staff (and while a reply or edit form is open), and in the Reply row on the guest page. It shares the toggle's size through one constant, `TICK_SIZE` (32px, 44px on touch and at <=721px), so the two cannot drift.
- Guest resolved status: same `ResolvedTick` (guest code may import `components/quincy/`; no staff modules). Replaces `reui/badge variant="success"`.

## Open-state colour

The open toggle uses `text-muted-foreground` (greige-400 `#8f8775`) on `--card` (`--bg-surface`, `#ffffff`): 3.57:1, which clears the 3:1 non-text floor (WCAG 1.4.11) for a glyph. Dark mode resolves `--muted-foreground` to greige-300 on ink-800 (8.59:1).
