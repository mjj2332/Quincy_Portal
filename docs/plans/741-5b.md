# #741 PR 5b — settled plan (synthesis of deep-reasoner + Codex, 2026-10-10)

**Base plan:** `plan-5b-deep.md` (same folder). Follow it section by section. The overrides below win where they differ; items from the Codex plan (`plan-5b-codex.md`) that are adopted are listed explicitly — do not import anything else from it.

## Settled decisions
1. **Scope:** 5b is web only. Card note counts (deep D1 / override 16) move to a separate small PR "5b-counts" after 5b. No server change in 5b.
2. **Visibility default:** every fresh root composer starts **Internal**; reset after a successful post, on discard and on Version change. An unsent draft keeps its explicit choice (both plans agree).
3. **O key:** O marks the last included frame; stored `endFrame = f + 1` (half-open `[start, end)`, as the settled epic plan already says). I and O on the same frame = valid one-frame range. O on the final frame stores `frameCount`. A mark that crosses the other clears it (deep). The NLE export (8/9) uses the same half-open rule. Not an owner question.
4. **Filters:** two independent controls, status `Open/Resolved/All` (default Open) × visibility `All/Client-visible/Internal` (default All). Filter root threads; replies stay attached; counts count roots only. Markers follow the filters.
5. **Drafts:** deep D3 — typed text kept in memory per person + Version while the Video tab is open, marks always cleared, no discard prompt. Point anchors are frozen at the frame where composing started (Codex), not following playback.
6. **Version details:** behind a "Version details" popover in the header when notes are on (both).
7. **Markers:** deep D7 (mouse click picks nearest marker and seeks; hidden from AT, list is the accessible path) plus Codex's resize clustering rule. Public/internal distinguished by shape and label, not colour alone.
8. **Editing frames:** included (deep D8), 5a API supports it; frames locked when the note has markup (server refuses).
9. **Search:** none.
10. **Client-visible badge tone:** `info` (deep D9); design-reviewer may change.

## Adopted from the Codex plan
- Error handling: never auto-retry a create or reply after an ambiguous network failure; keep the draft and offer refresh. On 409 `note_conflict` show the server's current content beside the kept draft and require an explicit retry with the new revision.
- Frame confirmation on Post (pause and confirm the frame on screen) with a **10-second timeout** that keeps the draft and offers retry; cancelled on dismiss, Version change, close and principal change.
- Escape order: nested menus/confirms first, then the active composer/edit/reply, then the viewer (reason `escape-key`), honouring the ProjectSheet double-report note.
- Lessons to cite: "A focusable child inside a composite that owns keydown is a trap until you say otherwise (#206)" and "A range shortcut that sets both ends silently rewrites the one you were not editing (#683)", besides the deep plan's.
- Its browser-pass rows for Conflict and Version switch, added to the deep plan's list.
