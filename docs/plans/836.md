## 4. Risks, traps, decisions
- Agency on a public page contradicts the DTO comment "never anything about agents": the ticket decides it (agency = company); update the comment; never add agent/photographer.
- `--container-*` / dialog width (lesson #741 13c): hero height keyed on container, not viewport alone. Breakpoint spelling `max-[721px]` / `@max-[721px]` only (`config/phone-breakpoint.guard.test.ts`); TOUCH targets are `pointer-coarse` (lesson #692).
- Hero `overflow-hidden` would be a programmatic scroller: use `overflow-clip` (lesson "overflow: hidden is still a scroll container").
- Focus ring on the dark hero/footer comes from `data-surface="inverse"` (inverse.css sets `--focus-ring` paper); no hand-set outline colours (design guard #541).
- `ui-primitive-ratchet`: no raw `<button>`; `<img>`/`<a>` fine. `test-seam` guard F: assert by test-id/role, not `data-slot`.
- Decision — per-photo Web-size/Full-res anchors: KEEP below the tile (ticket "keep today's features"; #837 replaces them). Confirm with owner.
- Decision — Copywriting count: SHOW (ticket "each tab shows its count"; proto omits because its copy tab is an article, ours lists PDFs).
- Decision — counts: frames = Gallery photos, films = all films (proto). Decision — tab bar not sticky (ticket silent; Preview's scroller, lesson 4141). Decision — top-right hero wordmark (`.chero__credit`) omitted: only a black wordmark exists.
- Sibling overlap: none in `delivery/`; `client-delivery.ts` is shared with #834 only if it edits the same schema block: rebase carefully.
