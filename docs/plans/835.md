## Synthesis decisions
- Recipients: every video kind goes to active Project members whose role holds `viewVideo`, excluding the Actor; non-member Admins excluded; Admin recipients snapshotted as project members so delivery re-checks membership (both plans agree).
- Staff-recorded decisions stay silent (Opus, matches the spec; Codex suggested notifying — rejected as scope creep).
- New kinds `video_released` and `video_mention` go in every exhaustive map, with External copy narrowed ("Video review update" / "You were mentioned in a video note."). Digest cadence inherited.
- A withdrawn Release is suppressed at delivery; a mention must join a live note.
- Mention candidates for video: a scoped variant of the existing mentionable-users route (`scope=video`), not a new picker.
- Stored `body` carries the media hint; paste is text-only; no link previews in notes.
- Guest media read: attached media in public notes is readable whenever the guest can read notes; upload requires verified + allowComments (Codex's split, adopted).
- Guest upload quotas: per-guest and per-link 15-minute buckets (Opus: media:guest 20, media:link 100) plus staff per-file caps; no daily byte bucket in v1.
