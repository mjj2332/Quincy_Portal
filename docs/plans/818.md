# #818 Staff video Version download — settled plan

Synthesised from blind Opus and Codex plans (2026-10-12). Both agreed on route, capability, naming, Range, audit, MCP; the differences are settled below.

## Decisions
- **Who:** new capability `downloadVideo` → admin, editor, `EXTERNAL_EDITOR_CAPABILITIES`. Photographer no. Project visibility unchanged (`hasProjectAccess`; External editor miss = 404).
- **What:** any live Version (superseded/historical OK), released or not, premium/locked or not; original R2 bytes. Trashed Version or Video → 404. Archived Project follows existing visibility.
- **Flag:** new review part `download` (flag `video_review_download`, default off), appended to `VIDEO_REVIEW_PARTS`, `VIDEO_REVIEW_PART_CAPABILITY.download = "downloadVideo"`. Same shipping pattern as `export`/`trash`. (Codex wanted no flag; repo practice is dark-then-flag.)
- **Route:** new `workers/app/src/routes/video-download.ts`, `GET /api/projects/:projectId/video-versions/:assetId/download` (HEAD via GET), mounted beside `videoMarkerExportRoutes`. Inline checks, no `.use()` (lessons: "Hono router-wide middleware leaks across sibling mounts"). Order: ids 400 → gate+`download` part 404 → capability 403 → `hasProjectAccess` → one SELECT assets⋈video_version_meta⋈videos with `v.project_id` bound to the path id, `a.kind='video'`, `LIVE_VERSION`/`LIVE_VIDEO` → 404.
- **Stream:** `serveR2Object` with `VIDEO_STREAM_HEADERS` + attachment disposition, `authorize` re-checks `versionIsLive` (and gate/access) after R2 answers, including before 416. Range: yes. `/media/video/*` stays disposition-free (ADR 0020 §6).
- **Name:** extract `safeFileName`/`attachment`/entry name from `guest/download.ts` into `workers/app/src/lib/download-name.ts`; `videoVersionFileName(title, version)` → `"<Title> v<N>.mp4"` (#813: .mov stored as mp4). Guest re-exports, behaviour unchanged.
- **Audit:** `video_version.download`, target asset, meta `{projectId, videoId, version, bytes}` via `audit`/`auditMeta` (impersonation provenance automatic). Only on full GET (no Range or `bytes=0-`); not HEAD/resumed chunks/refusals. Re-check live right before audit.
- **Terminal route seed:** `{GET, "/api/projects/:projectId/video-versions/:assetId/download", class: "scoped"}`.
- **MCP:** no (allowlist unchanged; pin with an `isAllowedMcpRoute` false assertion).
- **Shared:** `videoVersionDownloadUrl(projectId, assetId)` in `packages/shared/src/video-review.ts`, used by web and tests.
- **UI:** `VideoCollectionPanel` derives `downloadEnabled = review.parts.includes("download") && roleHasCapability(role,"downloadVideo")`, passes `download={{projectId}}` to `VideoReviewViewer`. Viewer header (single view only), after the Version group: reui `Button variant="outline" nativeButton={false}` rendering `<a href download>`, `DownloadIcon`, text "Download", `aria-label="Download version N"`, `data-testid="video-download"`, `pointer-coarse:min-h-11 max-[721px]:min-h-11`; visible at 390 (do not copy Compare's `max-[721px]:hidden`). Hidden while comparing — no Compare A/B buttons (out of scope).
- **Docs:** ADR 0020 amendment (staff download is a separate audited route), `docs/maps/routes.md`, `docs/Guides/Video-Review-Cutover.md` (add part row, 13 parts), `packages/shared/GLOSSARY.md` "Version download (staff)".
