## Decisions where the spec is silent (synthesised; recorded so later slices don't reopen them)
- **Size cap:** 2,000,000,000 bytes (decimal "2 GB", as Finder shows it).
- **Probe interface:** `probeMp4(src: ByteSource)` with `ByteSource = { size; read(offset, length): Promise<Uint8Array> }` (browser `Blob.slice`, Worker ranged `MEDIA.get`). moov read in one bounded read (≤16 MiB), read budget ≤64 reads. CFR = one `stts` delta (final count-1 entry exempt); B-frame `ctts` is fine. Edit list: none, or one unit-rate entry with frame-aligned `media_time ≥ 0`; anything else rejected. Rotation 90/180/270 swaps dims; other matrices rejected. tmcd via `tref` else sole tmcd track; mismatched nominal → dropped with warning.
- **Rates:** store the file's exact rational; NTSC detection only for timecode labelling. Drop-frame only when tmcd says DF (nominal 30/60). Player shows source TC, else 00:00:00:00; export start defaults to 01:00:00:00 when tmcd is absent.
- **Frames:** ranges are half-open `[start, end)`; replies carry no frames. Paste maps a frame by its middle moment, exact BigInt maths; range ends map as boundaries; a 1-frame range never collapses.
- **Notes:** visibility is **immutable after creation** (replies inherit, no cascade edits). Delete with others' replies → tombstone (`deleted_at`, body + markup cleared). Resolve/reopen: any staff with note access, audited; guests can't resolve.
- **Markup:** separate `video_note_markup` table (≤512 KiB), cascade-deleted with its note; stroke zod schema moved to shared and re-imported by annotations.
- **guest_reviewers** table is created in 0068 so `video_notes.author_guest_id` gets a real FK; the rest of the guest schema is 0069 (incl. digest table + unsubscribe column — no third migration).
- **Video row** is inserted at upload completion in the same batch as the Asset, meta, predecessor supersede, audit and activity; an aborted first upload leaves no Video. One active reservation per Video (409 otherwise).
- **No Version/Video delete in v1** (immutability); only Project hard delete removes them.
- **EDL > 999 markers:** typed 422 with the count; UI points to FCPXML or filters. No chunking, no silent truncation.
- **Review link copy (story 66):** tokens are hash-only, so the one-click copy happens at creation while the token is in memory; afterwards "Replace link" rotates the token and kills sessions.
- **Photographers** get no video capability. External editors: upload + review + internal notes on assigned Projects; never links/Release.
- **Outbox actor** for guest-caused staff events: `guest:<guestId>`; consumers never look it up as a user.
- **Audit side doors:** `/media/asset/:id/original|web|thumb` must 404 for video assets; audit other `FROM assets` readers for kind filters in 4a.
