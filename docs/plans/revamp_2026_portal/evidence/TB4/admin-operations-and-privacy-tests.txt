TB4 Admin operations / privacy evidence (2026-08-26)

Passed TB4 assertions 13–15 prove:

  13. Admin delivery list supports pending_stuck, dlq, failed, and unknown views, cursor paging,
      safe error-code allowlisting, and the exact duplicate-email acknowledgement body. The
      serializer does not include payload_json, comment content/ID, recipient email, raw provider
      error, provider/path/contact data, or Queue message ID.
  14. Admin UI has all four filters, loading/empty/error/load-more/action states, and the visible
      Duplicate email possible warning/confirmation copy.
  15. Existing emitNotifications, notifyProject, notifyProjectAssignments, and
      notifySubtaskAssignee producers remain direct and unchanged in their paths.

Both replay and discard check active unexpired leases and return 409. Discard preserves unknown
email and converts processing email to unknown; it never creates a warning-free discarded email
ledger state and never deletes comment/inbox/audit/outbox/ledger data. Discard can no longer flip
a `suppressed` channel to `discarded` (Sol round 2 fix) — replay could otherwise resurrect a
channel that was correctly, intentionally suppressed. Replay's audit insert uses
`WHERE changes() >= 1`, not `= 1` (Sol round 1 fix) — its preceding ledger UPDATE legitimately
affects 2 rows in the default both-channels case, and the original `= 1` guard silently skipped
the audit for that (most common) case. Both routes fence their mutation on the outbox row's
`updated_at`, read once at the start of the handler and required to still match at write time
(Sol round 1), using a strictly monotonic value (`Math.max(Date.now(), existing.updatedAt + 1)`,
Sol round 2) so two concurrent requests racing the same row always produce exactly one 200 and one
409, regardless of ordering or millisecond timing.

The Admin Worker/DOM integration suites (admin.test.ts, Admin.dom.test.tsx) run and pass outside
any codex sandbox; see automated-gates.txt. No authenticated production session or manual/
screenshot evidence was created as part of this pass — that remains a separate manual-QA phase.
