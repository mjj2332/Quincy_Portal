# #933 — settled plan (Video tile tooltip, previous/next, Video rows)

Synthesised from two blind plans (Opus deep-reasoner, Codex). The **Settled decisions** section
wins over anything below it. Section "Base plan" is the Opus plan; "Codex additions" lists the
points from the Codex plan that the base plan lacked and that are adopted.

## Settled decisions

- **S1 Filtered-out / removed open film** (spec Implementation Decisions + #936 AC): no position,
  both step buttons disabled, `[`/`]` do nothing. Not story 25's "nearest shown film" reading
  (base plan D2 is overruled). A film whose Video disappears entirely (Trash) keeps today's
  behaviour: the viewer closes and focus goes where it goes today; neighbours drop it at once.
- **S2 Tooltip measurement**: measure the title element when the tooltip asks to open
  (`scrollWidth > clientWidth`); this is always current after any resize, so no ResizeObserver per
  tile. Zero width (jsdom) = does not overflow. `(pointer: coarse)` → no tooltip at all.
- **S3 Guest phone**: unchanged, no step control (pinned by `GuestApp.dom.test.tsx`).
- **S4 Staff phone**: step control in `ReviewPhoneBar` via an optional slot; guest passes nothing.
- **S5 Pane state across a step** (story 19): the open/closed state must survive a step in both the
  wide and the narrow layout. If `useReviewPane` holds transient state that a keyed remount loses
  (Codex), hoist the hook instance into the panel and pass it down; verify with a test either way.
- **S6 Keyed remount traps**: return `false` from `finalFocus` during a step's teardown (no focus
  theft to the old tile); `entry="step"` turns the dialog's entry animation off.
- **S7 Delivery stepping** keeps the player's current open behaviour (autoplay as today), keyed
  `PlainVideo` per film so load/error state resets; the old element pauses before removal.
  Stepping is scoped to one `FilmList` instance.
- **S8 Tablet widths**: follow `DashboardTable`'s own narrow-width behaviour if it has one;
  otherwise drop columns uploader → uploaded → notes until the title keeps ≥ 240px. Width 0 drops
  nothing.
- **S9 Phone/compact**: staff and guest use `PHONE_VIEWPORT_QUERY` (max 721px); delivery uses its
  container width (staff Preview hosts it at 720px).
- **S10 Shared open control**: `VideoTile` exports its open control (`VideoOpenControl`) and summary
  string; tile and row render the same control, so no raw primitive leaves `components/quincy/`
  and no ratchet allowlist entry is needed.
- **S11 Full row API ships with #938** (`VideoRows`: select/menu/footer/drop/rowAttrs slots, sort
  header, href|onOpen, locked, tone) together with the scoped `rowProps` seam on
  `reui/data-grid/data-grid-table.tsx` (adaptation note + regression test that Dashboard renders
  unchanged) and `useFileDropTarget` extracted from `FileDropzone`. After #938 merges,
  `VideoRows.tsx`, `VideoLayoutToggle.tsx`, `VideoTile.tsx` are frozen: a wave-3 change to them
  goes back to the session.
- **S12 Per-row file state (#939)**: panel-level keyed store (`createVersionFileState`), since a
  data-grid row's menu, drop and footer live in different cells.
- **S13 Header sort (#939)**: never cleared; new key → toolbar's natural direction; same key (incl.
  the vendor's clear step) → flip. `arrangeVideos` remains the only sorter.
- **S14 Guest/delivery and `@tanstack/react-table`**: settled by the owner, see "Owner decision" below.

## Owner decision (settled 2026-10-23)

**Approved by the owner:** "Approved: keep data-grid for guest/delivery Video rows, lazy-load them there, narrow guest-boundary.guard to ban @tanstack/react-router and @tanstack/react-query while allowing @tanstack/react-table by name with its reason, and make the specifier check transitive." The guard change and its header comment land with #940 (the first guest consumer); #941 relies on it.

Background:

`guest/guest-boundary.guard.test.ts` states guest and delivery reach no `@tanstack/*` "directly or
through anything it imports"; its transitive check only resolves project paths, so a shared
`VideoRows` on ReUI data-grid (which imports `@tanstack/react-table`) would pass the guard while
breaking its stated rule. Recommendation: keep data-grid (spec), lazy-load `VideoRows` on guest and
delivery, and make the guard enforce what it means: extend the transitive check to package
specifiers, ban `@tanstack/react-router` / `@tanstack/react-query` (the real hazards: URL
canonicalisation, staff cache) and allow `@tanstack/react-table` by name with the reason.
Affects #940 and #941 only.
