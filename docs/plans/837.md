# #837 settled plan (orchestrator synthesis of opus-837.md + codex-837.md)

Base: both plans in this folder. Where they agree, follow either. Where they differ, this file wins:

1. **Slideshow scope:** the ACTIVE tab's photos that are `!locked && url !== null` (unlocked Premium photos included; locked always excluded — story 3). Never filter on `!premium`. Hero Slideshow button beside Download all; hidden when the active tab has no eligible photo; single eligible photo opens static with playback disabled. Reuse the existing `DeliveryLightbox` (Embla, existing timer/autoplay, reduced-motion) with a slideshow mode — Codex §1 shape. Focus returns to the hero trigger.
2. **Share:** hero only (no tab-bar duplicate). `navigator.share({title,url})` from the click; else clipboard + inline "Link copied."; AbortError = cancel; other failures offer Copy link; clipboard failure shows an inline error. URL = absolute `/d/<slug>` on the current origin, no query/hash. Staff Preview has no Share.
3. **Per-photo Download:** each unlocked tile gets one always-visible Download anchor (original via `hrefs.download(handle)`, photo-specific accessible name, not nested in the Open button, ≥44px touch target on phones), replacing the below-tile Web-size/Full-res pair. Locked tiles and Preview: none. The **lightbox keeps its Web-size/Full-res pair** (Codex).
4. No server, DTO or migration change.
5. Tests per Codex §3 (DeliveryPage DOM + DeliveryLightbox.embla DOM); reuse ledger per element in `docs/plans/837.md`.
