## 4. Risks / traps / open decisions
- A missed call site would sort Delivered ascending silently; the required `stageKey` makes it a compile error.
- Direction belongs in the comparator, not a `reverse()` of the result (that puts undated first and flips ties).
- Moving out of Awaiting RAW can fill Shoot date server-side (lesson "Board order is derived, not stored (#470)"):
  never assert client slot == refetched order for that move.
- `styles/design-system-guards.test.ts`: reuse the existing token classes verbatim. ui-primitive ratchet does not
  cover `<p>`, so no allowlist entry.
- OPEN (copy, not blocking): "Oldest first" matches GLOSSARY:113; #833's "Soonest first" is wrong for past shoot
  dates. Recommend "Oldest first · Delivered newest first". Menu is `w-auto min-w-48`; text-xs ≈230px fits 390px.
  Browser pass: Agy at 1440/390 (menu open, choice changed, Delivered order); design-reviewer vs Table's Group by.
