## 4. Risks, traps, decisions
- **D1 Story 7 (decisions in UI) is unreachable without D1** — `/video-review` filters `delivery` by `releaseVideo`. Recommend D1 (contained: only `VideoCollectionPanel:71` reads the role-filtered `delivery`; `deliveryOffered` is #787's own gate; guest code reads the raw gate). Touches nothing in `delivery/` (#836). If declined, story 7 is route-only.
- **D2 Story 13 contradicts `visibleProjectWhere`** (`isNull(archivedAt)` for non-`viewAllProjects`): Externals get 404 on every archived-Project route, revoke included — the deliberate #527 rule ("#527 The Project discussion is read-only on an archived Project"; `video-notes.ts` `archivedResponse`). Keep; revoke on archived stays a staff action. Ticket also says the check order is unchanged.
- **D3 single-Video create does not replace the ticks** (rejected alternative: selection={id}). Clobbering a half-built multi-select is the "Form lifetime is not component lifetime (#741 5b)" failure. Label/passcode/expiry/allow draft is shared (as today) and visible in the form.
- **D4 card has no "existing menu"** (spec premise wrong); we add the first one. Hide both actions when archived (tick rule), not merely disabled.
- Non-nested modals: base-ui `useDialogRoot` closes only on its own backdrop, so a press in the links dialog doesn't close the viewer; viewer Escape relies on `hasOpenModalAbove` document order (links portal mounts at open, after the viewer) — pinned by the DOM test ("Escape needs an order…(#741 5b)").
- Overlap #835: stale "(Admin, Editor)/External sees name alone" comments at `routes/video-notes.ts:72`, `lib/video-notes.ts:34`, `shared/src/video-notes.ts:91`, `VideoNoteThread.tsx:52` — leave to whichever PR lands second; flag in PR body.
- Guards: `ui-primitive-ratchet` unaffected (no raw primitives); manifest `assertSecurityRouteManifest` unchanged routes; ADR 0008 unchanged (recipients keyed on `viewVideo`, `video-review-notifications.ts:36`); ADR 0021 secret handling unchanged (External sees `url` like staff — owner decision in ticket).
- Prod is fully gated on: merge = live; deploy via CI, no migration.
