# Retro: navigation and stale docs (last 10 sessions, 2026-09-30 → 10-05)

Scope: 10 orchestrator sessions and 394 subagents. Call counts are approximate because the traces replay after a resume.

## 1. docs/lessons.md has no index, is cited by line number, and conflicts on every merge
- It is 5,412 lines in 185 date-ordered sections, with mixed heading styles (`## #452 …` vs `## … (#456)`).
- About 800 commands referenced it, from 180 of the 394 subagents. Access is always `grep '^## '` followed by `sed -n` ranges.
- Agents missed lessons that already existed: UUID fixtures (`:4825`), Menu focus race (`:2049`), Gantt landing (`:4581`). A brief also cited `#446`, which has no entry.
- **Stale citations.** Five citations land in the wrong section: AGENTS.md:51, NavigationRail.tsx:82, ADR 0005:16 and ADR 0006:50 all cite `:1368-1380` for the router rule, which is now at `:1421`. NavigationRail.tsx:106 cites `:1689`, which is now about drag reflow. Three cite `:27-62` near the top of the file, before any heading, so they could not be checked this way.
- **Merge conflicts.** lessons.md had 19 real conflicts, costing about 63 calls. There is no `.gitattributes`.
- **Fixes:**
  - Add `.gitattributes` with `docs/lessons.md merge=union`.
  - Add a guard test that rejects `lessons\.md:\d+` and requires heading anchors instead.
  - Add a guard that enforces one heading form (`## #NNN Title`).
  - Commit a generated TOC grouped by area and issue number, with a guard that keeps it current.

## 2. No test/verify runbook; the canonical gate exists only in .github/workflows/portal.yml
- 55 runs got "No test files found" because `*.dom.test.tsx` only runs under `vitest.dom.config.ts`. No doc mentions that config.
- Agents used wrong workspace names: `@quincy/app`, `@quincy/app-worker`, `apps/worker-app`. The real one is `@quincy/worker-app`.
- Worker tests fail without `apps/web/dist`. That hint lives only in `lessons.md:621` and the test's `BUILD_HINT`.
- 3,475 of 3,799 test runs were piped to grep/tail with no saved log, so each new question re-ran the suite. The full suite takes over 120s.
- **Fixes:**
  - Add `npm run verify` that mirrors CI and writes per-step logs.
  - Add a `test:file` script that picks the right config.
  - Add a `pretest` check in workers/app that names the build command.
  - Write `docs/agents/runbook.md` and add a single pointer line to AGENTS.md.

## 3. macOS/zsh shell traps
- About 50 unquoted `--include=*.ts` greps hit zsh "no matches found".
- About 50 failures came from GNU-style `sed -i`.
- `timeout` failed 9 times or more.
- `${PIPESTATUS}` doesn't work under zsh, and a `bash` lowercase tool name showed up.
- **Fix:** add one positive AGENTS.md line: "macOS zsh: `sed -i ''`, quote globs or `rg -g`, `perl -e 'alarm N; exec @ARGV'` for time limits."
