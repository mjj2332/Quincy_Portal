## Rules (`docs/adr/0011-every-subtask-has-a-range.md`, `docs/adr/0016-every-subtask-end-is-a-moment.md`)
- Every Subtask has a range; no unscheduled or due-only state (0011). 0011's "one day at the shortest" is **amended** by 0016: the start only has to be before the end, by instant.
- Every start and end is a Sydney civil date-time; the date-only kind is retired (0016). A picked day with no time takes 09:00 for a start, 17:00 for an end: `SUBTASK_START_PRESET_TIME` portal/packages/shared/src/checklist-schedule.ts:12, `SUBTASK_END_PRESET_TIME` portal/packages/shared/src/checklist-schedule.ts:14 = `DEADLINE_PRESET_TIME` portal/packages/shared/src/project-deadline.ts:14.
- `DateTimeField variant="range"` is the only Subtask-range picker (0016). The server refuses a date-only end with `subtask_schedule_time_required`.
- Default range = shoot date 09:00 through the Deadline at its own time: `defaultSubtaskRange` portal/packages/shared/src/default-subtask-range.ts:44 (fallbacks in its doc comment), `defaultSubtaskRangeDto` portal/packages/shared/src/default-subtask-range.ts:95; the web reaches it through `projectDefaultFromFacts` portal/apps/web/src/lib/date-time-range.ts:84.
